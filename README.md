# Github-Issue-Tracker

১. var, let, and const এর পার্থক্য কী?

উত্তর:

var: পুরনো পদ্ধতি। এটি ফাংশন স্কোপড। একই নামে বারবার ডিক্লেয়ার করা যায়, যা অনেক সময় কোডে ভুল তৈরি করে।

let: আধুনিক পদ্ধতি। এটি ব্লক স্কোপড ( { } এর ভেতর কাজ করে)। মান পরিবর্তন করা যায়, কিন্তু একই নামে পুনরায় ডিক্লেয়ার করা যায় না।

const: এটিও ব্লক স্কোপড। একবার মান দিলে তা আর পরিবর্তন (Reassign) করা যায় না।

২. Spread Operator (...) কী?

উত্তর: স্প্রেড অপারেটর (...) ব্যবহার করে কোনো অ্যারে বা অবজেক্টের সব ডাটা একবারে কপি করা বা অন্য কোথাও ছড়িয়ে দেওয়া যায়। এটি কোড ছোট করতে সাহায্য করে।

৩. map(), filter(), এবং forEach() এর পার্থক্য কী?

উত্তর: * forEach: শুধু লুপ চালানোর জন্য (কোনো কিছু রিটার্ন করে না)।

map: অ্যারের প্রতিটি উপাদানে পরিবর্তন এনে একটি নতুন অ্যারে তৈরি করে।

filter: শর্ত মিলেছে এমন উপাদানগুলো নিয়ে একটি নতুন অ্যারে তৈরি করে।

৪. Arrow Function কী?

উত্তর: এটি ফাংশন লেখার একটি আধুনিক ও সংক্ষিপ্ত পদ্ধতি। এতে function কিওয়ার্ডের বদলে => চিহ্ন ব্যবহার করা হয়।

৫. Template Literals কী?

উত্তর: ব্যাকটিক ( ` ) ব্যবহার করে স্ট্রিং লেখার পদ্ধতি। এতে ${ } ব্যবহার করে খুব সহজে স্ট্রিংয়ের ভেতরে ভেরিয়েবল বসানো যায় এবং সরাসরি এন্টার দিয়ে নতুন লাইনে লেখা যায়।
